## ▶️ Como Executar

### 1. Clone o repositório

```bash
git clone https://github.com/cezarsillva/portfolio.git
```

### 2. Acesse a pasta

```bash
cd portfolio
```

### 3. Abra o projeto

Abra o arquivo:

```text
index.html
```

Você pode utilizar o **Visual Studio Code** e uma extensão como **Live Server** para executar o projeto localmente.
